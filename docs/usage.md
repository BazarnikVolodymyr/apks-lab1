# Використання

## Запуск агента у VS Code

1. Відкрийте папку проєкту у VS Code.
2. Відкрийте Copilot Chat.
3. Виберіть агента `build-engineer`.
4. Виконайте команду:

```text
/init
```

Після створення або перевірки структури проєкту запустіть фінальну
перевірку:

```text
/check
```

## Локальна збірка

На Linux або macOS із кореня репозиторію виконайте:

```bash
./ci.sh
```

На Windows із кореня репозиторію виконайте:

```bat
ci.bat
```

Скрипти виконують конфігурацію CMake, збірку у конфігурації `Release`,
запуск CTest і копіюють executable до каталогу `dist/`.

## Запуск програми

На Linux або macOS:

```bash
./dist/hello
```

На Windows:

```bat
dist\hello.exe
```

Програма виводить повідомлення `Hello, World!`.

## Запуск тестів

Після успішної збірки запустіть усі тести командою:

```text
ctest --test-dir build -C Release --output-on-failure
```
